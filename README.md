# List of resources I'm using to learn Rust

## Ordered list

The order below is my opinionated guess. My guess is getting more informed as I read more of the resources.

1. [x] [The Rust Programming Language](https://doc.rust-lang.org/book/)  
   * [x] Recommended: [Supplemented with quizzes](https://rust-book.cs.brown.edu/)  
   * [ ] Alternative / extra: [Rust by Example](https://doc.rust-lang.org/rust-by-example/)
         \- maybe good for LLMs?

2. [ ] [The Command line book](https://rust-cli.github.io/book/index.html)
      \- incomplete, still very useful for starting writing useful tools

3. [x] [Rust for Rustaceans](https://nostarch.com/rust-rustaceans)

4. [x] [Rust API Guidelines](https://rust-lang.github.io/api-guidelines/)

5. [x] [The Rustdoc book](https://doc.rust-lang.org/rustdoc/)

6. [ ] [The Clippy book](https://doc.rust-lang.org/stable/clippy/)

7. [x] [The Little Book of Rust Macros](https://lukaswirth.dev/tlborm/)

8. [ ] [The Cargo book](https://doc.rust-lang.org/cargo/)

9. [x] [The Rustonomicon](https://doc.rust-lang.org/nomicon/)
       \- marked as incomplete

10. [ ] [The Rust Style Guide](https://doc.rust-lang.org/style-guide/)

11. [ ] [Learn unsafe Rust](https://google.github.io/learn_unsafe_rust/)
        \- currently archived

12. [ ] [The Embedded Rust Book](https://doc.rust-lang.org/embedded-book/)

13. [ ] [Effective Rust](https://effective-rust.com/)

14. [ ] [Unsafe Code Guidelines Reference](https://rust-lang.github.io/unsafe-code-guidelines/)
       \- listed as abandoned, only glossary is maintained

15. [ ] [The Rust Reference](https://doc.rust-lang.org/reference/)
  



## Indexes

[The Rust Bookshelf](https://doc.rust-lang.org/) is a list of documentation
resources owned by the official Rust maintainers. Most documentation there
is built on top of [mdbook](https://github.com/rust-lang/mdBook).
